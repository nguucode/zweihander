# Templates

Page frames and whole pages, assembled from Patterns and Components
(atomic design's "templates"). Where a pattern is one section of a screen, a template is
the screen: an app shell, a heading, a toolbar and the content, wired
together on sample data so you can click through it.

Templates are meant to be **copied and edited**, like Patterns. They ship
through the registry only, not the npm package: install one and its files
land in your project, next to the patterns and components it uses, as
code you own.

```sh
npx shadcn@latest add https://ontheshore.biz/zweihander/r/projects-template.json
```

Each template is one React component plus a sample data file. The state
(tabs, search, sort, selection) is local, so it runs as it is; replace the
data and the handlers with your own source when you copy it. Every
template is checked for accessibility in light and dark mode, like any
component.
