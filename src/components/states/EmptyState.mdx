# Empty State

<DocTabs>
<DocTab value="overview">

What a list, a table or a page shows when there is nothing in it yet: why
it is empty, and what to do about it.

<Canvas of={EmptyStateStories.FirstUse} />

## Variants

There are three kinds of empty, and they need three kinds of copy. The
component is the same; the words and the action are not.

| Kind | Use for |
| --- | --- |
| First use | Nothing has been made yet. Say what will live here, and offer the way in: "No projects yet", New project. |
| No results | A search or a filter matched nothing. Say what was searched, and offer to clear it: "No projects match", Clear search. |
| Cleared out | Everything is done. Often no action at all: "All caught up". |

## When to use

Use an Empty State wherever a list, a table or a page can have nothing in
it: before the first item is made, after a search matches nothing, when
everything is done. Write the title for the reader's situation, and give
them the next step.

<DoDont
  do={<Story of={EmptyStateStories.FirstUse} />}
  doCaption="Say what is empty and what will live here, and offer the way in."
  dont={<Story of={EmptyStateStories.DontNoData} />}
  dontCaption="“No data” says neither why nor what to do next."
/>

## When not to use

- **When loading failed.** Use an
  [Error State](?path=/docs/components-states-errorstate--docs): "No
  projects" when the request failed tells the reader their work is gone.
- **When a flow has finished.** Use a
  [Success State](?path=/docs/components-states-successstate--docs).
- **While content is loading.** Use a Skeleton or a Spinner: an empty
  state shown before the data arrives flashes the wrong message.

## Accessibility

- The title is a real heading, so a screen reader user jumping by
  headings finds out the area is empty. Set `headingLevel` to fit the
  outline: `3` inside a section headed by an `h2`.
- The icon is `aria-hidden`; the title has to say it all.
- It is not a live region, so it is not announced when it replaces
  results. If a search updates as you type, announce the count elsewhere,
  in a `role="status"` line such as "0 results".
