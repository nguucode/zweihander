## Variants

`variant` is the colour, by meaning; `appearance` is the emphasis. Any
variant takes any appearance.

<Canvas of={ButtonStories.Matrix} />

| Variant | Use for |
| --- | --- |
| <Button>Primary</Button> | The next step: Save, Continue, Create. One per view. |
| <Button variant="accent">Accent</Button> | A strong action in neutral black or white, where the brand colour would clash or already means something else. |
| <Button variant="secondary">Secondary</Button> | Everything else: Cancel, Back, Export. |
| <Button variant="destructive">Destructive</Button> | Deleting, or anything that cannot be undone. |

| Appearance | Use for |
| --- | --- |
| <Button>Contained</Button> | The action to take, filled so it is found first. |
| <Button appearance="outlined">Outlined</Button> | Actions that matter but are not the next step. |
| <Button appearance="ghost">Ghost</Button> | Low emphasis and dense places: toolbars, table rows, a card's corner. |

- **Hover and pressed** are mixed from the variant's own colours, not a
  token each. A coloured solid (primary, destructive) moves away from its
  label and gains contrast; accent and secondary move toward it. Outlined
  and ghost tint the background with their tone, 8% on hover and 14% when
  pressed. Every state keeps the label at 4.5:1, measured by the
  `StateContrast` story under all seventeen accents in both modes.
- **Focus** is a 2px `--ring` outline, 2px outside the button.
- **Disabled** is the enabled look at 50% opacity.
- **Loading** keeps the full colour: the button is busy, not unavailable.

### Differences from the spec

- **Two sizes, not four.** `sm` (24px) and `md` (32px) only, the compact control scale of the Claude apps. The spec's larger steps were dropped; a big call to action is `md` with more room around it, not a taller box.
- **`disabled`, not `isDisabled`**: the native attribute keeps its name.
- **`isIconOnly` is added.** The spec has no icon-only button, and a
  square button that still requires a name is common enough to need one.
- **`render` is added** for composition with routers and other elements,
  matching Base UI and shadcn. It replaced `asChild` in 0.8.
- **`accent` is the inverted neutral** (foreground on background), as on
  Badge: the token set has one brand hue and `primary` uses it.
- Outlined and ghost `primary` use `--primary-text`, a step of the accent
  measured to read at 4.5:1 on the page. The solid step would not, for
  warm accents.

## When to use

Use a Button for an action on the current page: save, submit, open a
dialog, delete. Use one `primary contained` button per view, for the thing
to do next. Everything else steps down to `outlined` or `ghost`, or to
`secondary`.

<DoDont
  do={<Story of={ButtonStories.DoOnePrimary} />}
  doCaption="One primary button: the thing to do next. The rest step down."
  dont={<Story of={ButtonStories.DontTwoPrimaries} />}
  dontCaption="Two primary buttons compete for the same click."
/>

**Loading** keeps the button's width and focus and blocks it from acting
again, so a double-submit is impossible and a keyboard user is not dropped
back to the top of the page.

<DoDont
  do={<Story of={ButtonStories.Loading} />}
  doCaption="Show progress with isLoading: the button stays where focus is, and cannot fire twice."
  dont={<Story of={ButtonStories.DontDisableWhileSaving} />}
  dontCaption="Disabling it to show progress drops keyboard focus and reads as unavailable."

## When not to use

- **To navigate.** A link is not a button. Pass `href` and Button renders a
  real `<a>`: it keeps link semantics, opens in a new tab on middle-click,
  and gets the link cursor. A plain Button with an `onClick` that changes
  the page does none of that.
- **For a setting that stays on or off.** Use a
  [Toggle Button](?path=/docs/components-buttons-togglebutton--docs), a
  Switch or a Checkbox.
- **For a link inside running text.** Use Link.

## Accessibility

- A native `<button>`, `type="button"` by default so it never submits a
  form by accident. Enter and Space both activate it.
- `isIconOnly` needs `aria-label`; TypeScript refuses it without one.
  Icons are `aria-hidden` everywhere else, so they never double the name.
- `isLoading` sets `aria-busy` and `aria-disabled` but keeps the button
  focusable. `disabled` removes it from the tab order, as native buttons
  do.
- A disabled or loading link renders a bare `<a>` with no `href` (the
  only thing that stops an `<a>` navigating) and `aria-disabled`. With
  `render`, the render element is dropped too, since a router's Link would
  keep its own `href`.
- `render` is for elements that are already interactive: a link or a
  router's Link. It merges props onto the element and adds no role or
  keyboard handling, so do not render a `<div>` through it.
- Hover and pressed keep the label at 4.5:1 too. The `StateContrast`
  story measures every variant × appearance × state under all seventeen
  accents in both modes, from the CSS that ships.
- `sm` and `md` are under 44px; on touch screens (`pointer: coarse`) the
  hit area grows to 44×44px without the button growing.
- Focus ring: 2px `--ring`, 2px offset, at 3:1 or better on the page.
