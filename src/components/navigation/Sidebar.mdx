# Sidebar

<DocTabs>
<DocTab value="overview">

The app's main navigation, down the side of the screen: a header, links
in named groups, and a footer. It can collapse to an icon rail.

<Status of={SidebarStories} />

<Canvas of={SidebarStories.Default} />

## Variants

| Variant | Use for |
| --- | --- |
| Expanded | The default: icon, label and badge on every row. |
| Collapsible (`isCollapsible`) | Apps where the content needs the width at times: a button in the header folds the sidebar to the rail. |
| Rail (`isCollapsed` or `defaultCollapsed`) | Icons only, labels in tooltips. For tools the reader knows well. Every item needs an icon. |
| Plain | No header or footer: a section's own navigation inside a larger layout. |

- **Current** is a `--selected` fill, a step past the hover fill so the
  two never read alike, plus medium weight for anyone who cannot tell the
  fills apart. It stays off the accent: where you are is not a call to
  action.
- **Focus** is a 2px `--ring` outline drawn inside the row, so rows that
  sit flush do not cover each other's ring.
- **Collapsed** is the rail; see Variants.

## When to use

Use a Sidebar for an app's main navigation when it has more than five or
so destinations, or will grow: the list runs down and does not wrap. Name
groups by what is in them, keep labels to a word or two, and give every
item an icon if the sidebar can collapse.

<DoDont
  do={<Story of={SidebarStories.DoGroupWithIcons} />}
  doCaption="Short labels, an icon on each, grouped under a few names."
  dont={<Story of={SidebarStories.DontLongLabelsNoIcons} />}
  dontCaption="Long labels get cut, and with no icons there is nothing to show in the rail."
/>

## When not to use

- **For three to five sections of one page or object.** Use
  [Tabs](?path=/docs/components-navigation-tabs--docs) across the top.
- **For actions.** A sidebar goes places. Put actions in
  [Buttons](?path=/docs/components-buttons-button--docs) or a
  [Menu](?path=/docs/components-navigation-menu--docs).
- **On a phone, as is.** 16rem is most of a phone's width. Put it in a
  drawer, as the [App Shell](?path=/docs/patterns-application-ui-app-shell--docs)
  does.

## Accessibility

- A `<nav>` landmark named "Main"; rename it with `aria-label` when the
  page has another navigation. The current item has
  `aria-current="page"`.
- Each group's label names its list through `aria-labelledby` ("Projects,
  list, 3 items"), and keeps doing so in the rail, where it is only
  visually hidden. Labels are not headings, so they do not compete with
  the page's outline.
- In the rail each link keeps its name through `aria-label`, badge
  included ("Inbox, 12"), and a tooltip shows the same text on hover and
  on keyboard focus.
- The collapse button is named "Collapse sidebar" / "Expand sidebar" and
  carries `aria-expanded`.
- Rows are 32px tall, 44px on touch screens (`pointer: coarse`).
