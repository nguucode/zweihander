# Command Palette

<DocTabs>
<DocTab value="overview">

A search box over the page that finds a command or a record by typing and
runs it with Enter, without a mouse. Opened by its trigger or by ⌘K
(Ctrl+K).

<Status of={CommandPaletteStories} />

<Canvas of={CommandPaletteStories.Default} />

## Variants

There is one palette; what changes is what you put in its groups.

| Content | Use for |
| --- | --- |
| Commands | Actions a power user repeats: New invoice, Export ledger. Give each its `shortcut` when it has one, so the palette teaches the key. |
| Records | Objects to jump to, grouped by type: Customers, Invoices. Load them from your search as the user types, or pass the few that matter. |
| Recent | What the user opened last, as the first group. The palette does not remember it for you: pass it from your app's history. |

Typing matches the label and `keywords`, ignoring case and accents, so
"bill" finds New invoice and "hoa binh" finds Hòa Bình Trading.

The container is at most 40rem wide and never wider than the screen. It
sits near the top, at 12% of the screen height, not centred: the list
grows and shrinks as you type, and the input stays where the eye is. The
list shows about ten rows (24rem) and then scrolls; the search row and the
key hints stay. The search icon lines up with the item icons. Items are
the [Menu](?path=/docs/components-navigation-menu--docs)'s rows; shortcuts
are [Kbd](?path=/docs/components-atomic-elements-kbd--docs) `sm`.

## States

<States
  states={[
    { label: 'Results', content: <Story of={CommandPaletteStories.Results} /> },
    { label: 'No results', content: <Story of={CommandPaletteStories.NoResults} /> },
  ]}
/>

- **Highlighted** is where the arrow keys or the pointer are: an `--accent`
  fill, the icon taking the text colour. The first match is always
  highlighted, so Enter always does something. Focus stays in the input;
  the highlight is the list's `aria-activedescendant`.
- **Disabled** items are muted at 60% opacity. The arrow keys still reach
  them, so a screen reader hears that they exist, but Enter and a click do
  nothing.
- **No results** shows `emptyText` and no group labels.
- The input has no focus ring of its own: it is the palette's only field,
  and the caret shows where typing goes.

### Differences from the spec

The queue's anatomy lists the open shortcut, an empty state and recent
results as parts. Here the shortcut is behaviour (`hotkey`, and a Kbd on the
trigger), the empty state is a state (under States), and Recent is a group
you pass: the palette does not store history.

## When to use

In an app with many pages and actions, as a fast way around for people who
use it every day: jump to a record, run a command, without going through
the navigation. Open it from a search button in the sidebar
(`NavSidebarButton appearance="field"`) and from ⌘K.

<DoDont
  do={<Story of={CommandPaletteStories.DoGroup} />}
  doCaption="Group the results, start each command with a verb, and put records under their type. Recent first."
  dont={<Story of={CommandPaletteStories.DontMix} />}
  dontCaption="One list of bare nouns: Invoice could mean open one, create one or list them all."
/>

Keep the palette a shortcut, not the only way: everything in it must also
be reachable from the navigation or a button on the page.

## When not to use

- **To search inside one list or table.** Use a search field above it,
  which filters what is on the page.
- **To pick a value in a form.** Use a
  [Combobox](?path=/docs/components-inputs-combobox--docs): it fills a
  field, the palette runs something.
- **For a handful of actions on one object.** Use a
  [Menu](?path=/docs/components-navigation-menu--docs) on that object.

## Accessibility

- The container is a `role="dialog"` named "Command palette" (`label`).
  Opening moves focus to the search input and traps it inside; closing
  returns focus to the trigger.
- The input is a `role="combobox"` named "Search commands" (`inputLabel`), its
  description the key hints: "Arrow keys to move, Enter to choose, Escape to
  close". The drawn hints are hidden, so they are read once.
- Each group is a `role="group"` named by its label; each item is a
  `role="option"`. A shortcut is drawn, not read: the item's name is its
  label.
- Up and Down move the highlight and the first match is highlighted; Enter
  chooses it, as does a click. A disabled item is reachable but Enter does
  nothing on it. The choice runs once the palette has closed and focus is
  back on the trigger.

  <Canvas of={CommandPaletteStories.Keyboard} />

- Escape closes it, as does a press outside.

  <Canvas of={CommandPaletteStories.Empty} />

- ⌘K or Ctrl+K toggles it from anywhere on the page; one palette per page
  should own that key, and the others set `hotkey={false}`.

  <Canvas of={CommandPaletteStories.Hotkey} />

Give the trigger `aria-keyshortcuts="Meta+K Control+K"` when the palette
owns the key, as the trigger in these examples does.
