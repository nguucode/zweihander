# Link

Text that takes you somewhere: another page, a section of this one, an
outside site. It navigates; it does not act.

## Variants

`variant` is the colour; `underline` says whether the line shows at rest.
Any variant takes either underline.

<Canvas of={LinkStories.Variants} />

| Variant | Use for |
| --- | --- |
| <Link href="#link">Primary</Link> | Links in running text and on their own. The default. |
| <Link href="#link" variant="accent">Accent</Link> | Links in the foreground colour, where the brand colour would compete: dense lists, navigation. |
| <Link href="#link" variant="secondary">Secondary</Link> | Footers, captions and meta text, where the link is not the point. |

| Underline | Use for |
| --- | --- |
| <Link href="#link">Always</Link> | Inside running text, where only the line tells a link from the words around it. The default. |
| <Link href="#link" underline="hover">Hover</Link> | Places that are obviously lists of links: a nav list, a footer column. |

Without a `size`, a link takes the size of the sentence around it, which
is what a link in text wants. `sm`, `md` and `lg` are for links that stand
alone.

- **Hover** thickens the underline from 1px to 2px and keeps the colour,
  so the link keeps the contrast it was measured at. With
  `underline="hover"`, hover is when the line appears.
- **Focus** is a 2px `--ring` outline, 2px outside the text.
- **Disabled** is the enabled look at 50% opacity, with no `href`.
- There is no visited style: most links in an app lead to screens, not
  documents, and a "seen it" colour there is noise.

## When to use

Use a Link to go somewhere: another page, a section of this one, a file,
an outside site. Inside a sentence, keep the underline; let the link
text say where it goes, so it still makes sense read on its own.

<DoDont
  do={<Story of={LinkStories.DoSayWhere} />}
  doCaption="The link text names the destination: it reads on its own, in a screen reader's list of links too."
  dont={<Story of={LinkStories.DontClickHere} />}
  dontCaption={'"Click here" says nothing out of context, and hides where the link goes.'}
/>

Mark links that leave for another site with `isExternal` only when they
open a new tab, and keep that rare: a new tab breaks the Back button.

With a router, pass its link as `render`. Link merges its class and props
onto it, and the router keeps control of navigation:

```tsx
<Link render={<RouterLink to="/settings" />}>Settings</Link>
```

## When not to use

- **For an action.** Saving, deleting or opening a dialog is a
  [Button](?path=/docs/components-buttons-button--docs). A link-styled
  action looks like it will take you away, and does not respond to Space.
- **For a prominent call to action that navigates.** Use a Button with
  `href`: it renders an `<a>` with the weight of a button.
- **For a trail of parent pages.** Use Breadcrumbs.
- **For moving through pages of a list.** Use Pagination.

## Accessibility

- A real `<a href>`, so it is in the tab order, opens with Enter, and
  shows up in a screen reader's list of links.
- Underlined by default: colour alone does not mark a link for someone who
  cannot tell the colours apart (WCAG 1.4.1).
- `isExternal` adds "(opens in a new tab)" to the accessible name, and
  sets `rel="noopener noreferrer"`: a new tab that opens without warning
  strands people who cannot see it happen.
- `isDisabled` removes `href`, the only thing that stops an `<a>`
  navigating, drops the click handlers and sets `aria-disabled`. Without
  an `href` it leaves the tab order. Prefer hiding a link that cannot be
  followed, or saying in text why it is unavailable.
- Every variant is a text colour measured at 4.5:1 on the page, and hover
  does not change it.
- Focus ring: 2px `--ring`, 2px offset.
