# Menu

<DocTabs>
<DocTab value="overview">

A list of actions that opens from a button: the "…" on a row, an
"Actions" dropdown, a "View" menu of toggles. It acts or toggles; to pick a
value for a form, use a [Select](?path=/docs/components-inputs-select--docs).

<Status of={MenuStories} />

<Canvas of={MenuStories.Default} />

## Variants

Menu has one look. What changes is the kind of entry in `items`, and a
menu can mix them:

| Entry | Use for |
| --- | --- |
| Action (the default) | Something to do now: Edit, Duplicate, Delete. Closes the menu. `isDestructive` draws it in the danger colour. |
| Link (`href`) | Going somewhere: Documentation, Settings. A real `<a>`. |
| Submenu (`items`) | A set of choices that belongs under one item: Move to, Share with. |
| Checkbox (`type: 'checkbox'`) | Settings that are on or off, several at a time: Show hidden files. Keeps the menu open. |
| Radio (`type: 'radio'`) | One of a few settings: Sort by name, date or size. Keeps the menu open. |
| Group (`type: 'group'`) and separator | Structure for a longer menu: a label over related items, a rule between sets. |

## Measurements

The item follows Atlassian Design's dropdown item: 8px block and 12px
inline padding around a 20px line, so a one-line item is 36px tall. The
box ramp has no 36px step, so the md control tier (32px) is the floor and
the padding makes the rest. The rest is Atlassian's dropdown menu too
(its newer menu): items sit 12px inside the popup and 2px apart, with a
6px corner and 12px between icon and label; a shortcut or a chevron sits
24px after the label; a separator runs edge to edge with 12px above and
below; a group label has 8px block padding, 12px before and 24px after.
The popup's padding counts its 1px border.

## States

<States
  states={[

- **Highlighted** is where the arrow keys or the pointer are: a `--accent`
  fill, the icon taking the text colour. A submenu's item stays highlighted
  while its submenu is open. Focus moves with the highlight, so there is no
  separate focus ring inside the popup.
- **Disabled** items are muted at 60% opacity and skipped by the arrow
  keys (Archive, above).
- **Checked** checkbox and radio items show the check; unchecked ones keep
  the empty column.
- The trigger's own hover, focus and pressed states are the
  [Button](?path=/docs/components-buttons-button--docs)'s.

## When to use

Use a Menu for actions that belong to one thing but would crowd the
screen as buttons: the actions on a table row, a card's overflow, a
toolbar's "More". Keep it short, put the most used item first, and give
destructive actions the last place, after a separator.

## When not to use

- **To pick a value for a form.** Use a
  [Select](?path=/docs/components-inputs-select--docs), or a
  [Combobox](?path=/docs/components-inputs-combobox--docs) when the list
  is long enough to search.
- **For one or two actions.** Show them as
  [Buttons](?path=/docs/components-buttons-button--docs): a hidden action
  is one fewer person finds.
- **For the app's main navigation.** Use a
  [Nav Sidebar](?path=/docs/patterns-application-ui-nav-sidebar--docs) or
  [Tabs](?path=/docs/components-navigation-tabs--docs), which show where
  the reader is.
- **For content: a form, a preview.** Use a
  [Popover](?path=/docs/components-overlays-popover--docs). A menu holds
  only menu items.

## Accessibility

- The trigger has `aria-haspopup="menu"` and `aria-expanded`; the popup
  is a `role="menu"` of `menuitem`, `menuitemcheckbox` and
  `menuitemradio`, with `aria-checked` on the toggles and
  `aria-disabled` on disabled items.
- Keyboard: Enter, Space or Arrow Down on the trigger opens it; arrows
  move (disabled items are skipped), typing a few letters jumps to the
  matching item, Enter selects, Arrow Right opens a submenu and Arrow
  Left closes it, Escape closes and returns focus to the trigger.
- Toggles keep the menu open, so several can be changed in one go;
  actions close it and focus returns to the trigger.
- The icon and shortcut are hidden from assistive tech; the label names
  the item. Give `textValue` when a label is not plain text, or typeahead
  cannot find it.
- A disabled link has no `href`, so it cannot be followed.
- Items are 36px tall, 44px on touch screens (`pointer: coarse`).
- `isModal` (the default) makes the rest of the page inert while the menu
  is open, so a screen reader stays in the menu.
