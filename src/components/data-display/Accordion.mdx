# Accordion

<DocTabs>
<DocTab value="overview">

A stack of headings that each show or hide a section of content: FAQs,
settings groups, long forms split into parts.

<Status of={AccordionStories} />

<Canvas of={AccordionStories.Default} />

## Variants

`appearance` chooses the frame, `size` the scale. By default one item is
open at a time; `multiple` lets several stay open.

| Appearance | Use for |
| --- | --- |
| `outlined` | A self-contained block on the page: an FAQ, a settings group. The items sit in a bordered panel. |
| `flush` | Sections inside something that already has a frame, such as a card or a sidebar. Edge to edge, no side padding. |

<Canvas of={AccordionStories.Open} />

<Canvas of={AccordionStories.Flush} />

| Size | Use for |
| --- | --- |
| `md` | The default: 32px triggers, 14px text. |
| `sm` | Dense panels and side columns: 24px triggers, 12px text. |

<Canvas of={AccordionStories.Small} />

| Mode | Use for |
| --- | --- |
| Single (default) | Sections a reader compares one at a time. Opening one closes the other. |
| `multiple` | Sections a reader may want side by side, such as settings groups. |

<Canvas of={AccordionStories.Multiple} />

## States

<States
  states={[
    { label: 'Enabled' },
    { label: 'Hover', pseudo: 'hover' },
    { label: 'Focus', pseudo: 'focus-visible' },
    { label: 'Pressed', pseudo: 'active' },
    { label: 'Open', content: <Story of={AccordionStories.Open} /> },
    { label: 'Disabled', content: <Story of={AccordionStories.Disabled} /> },
  ]}
>
  <Story of={AccordionStories.Default} />
</States>

- **Hover** fills the trigger with `--accent`. A disabled trigger does not
  change on hover.
- **Focus** is a 2px `--ring` outline. In `outlined` it sits 2px inside
  the trigger, because the frame clips anything outside; in `flush` there
  is no clipping and no side padding, so it sits 2px outside instead.
- **Pressed** has no look of its own: the trigger keeps its hover fill
  while the pointer is down.
- **Open** turns the chevron to point up, and the panel's height animates
  from 0 to its content's height over `--duration-base`.
- **Disabled** dims the trigger to 50% opacity, on one item
  (`disabled` in `items`) or on all of them (`disabled` on the accordion).

when `multiple` is switched on. `headingLevel` exists because a heading
level must follow the page's outline, which the component cannot know.

## When to use

Use an Accordion for several related sections that most readers only
need some of: an FAQ, groups of settings, the parts of a long form. Each
title should say what is inside, so a reader can pick without opening
every item.

<DoDont
  do={<Story of={AccordionStories.DoRelatedSections} />}
  doCaption="Several related sections, each title naming what is inside."
  dont={<Story of={AccordionStories.DontSingleItem} />}
  dontCaption="One item is not a list of sections. Use a Collapse."
/>

Set `headingLevel` to fit the page: under an `h2`, the items are `h3`, the
default.

<Canvas of={AccordionStories.Headings} />

## When not to use

- **For one section.** Use a
  [Collapse](?path=/docs/components-data-display-collapse--docs): a text
  button that belongs to the content around it.
- **For views of the same thing, one at a time.** Use
  [Tabs](?path=/docs/components-navigation-tabs--docs).
- **For content most readers need.** An accordion trades a shorter page for
  an extra click on everything inside it. Show that content.

## Accessibility

- Each trigger is a `<button>` inside a real heading, with
  `aria-expanded` and `aria-controls`; each panel is a region labelled by
  its trigger.
- `headingLevel` sets the heading element, `h3` by default.
- **Every trigger is a tab stop.** Enter and Space toggle. There is no
  arrow-key movement between triggers, following the current APG
  guidance (Base UI dropped it too).
- A disabled item's trigger has `aria-disabled` and does not open.
- Collapsed panels are `hidden="until-found"`: the browser's find-in-page
  reaches their text and opens the item.
- Triggers are 32px (`sm` 24px), the compact control scale. On touch
  (`pointer: coarse`) they grow to 44px rather than overlapping each
  other with invisible hit areas.
- The open/close animation stops under `prefers-reduced-motion`.
