# Column Chooser

<DocTabs>
<DocTab value="overview">

A button above a table that opens a list of its columns, each with a
checkbox to show or hide it, and a Reset that brings back the default set.

<Status of={ColumnChooserStories} />

<Canvas of={ColumnChooserStories.Open} />

## Variants

| Variant | Use for |
| --- | --- |
| Every column shown (default) | Tables whose columns all matter at first, where people hide what they do not need. |
| `defaultVisibleKeys` | Tables with more columns than fit: show the essentials, let people add the rest. Reset goes back to this set. |

The chooser does not touch the table: it reports the shown keys and you
filter the Table's `columns` with them. That keeps the choice yours to
store, per user or per view. With a resizable Table, pass `onReset` to put
the widths back too:

## Color

The chooser adds no colour of its own: the button is an outlined secondary
Button, Reset a ghost secondary Button, and the surface is Popover's
`--popover`. See those pages for their tokens.

## States

The chooser is open or closed. The button keeps Button's states; each box
keeps Checkbox's, and a locked column shows Checkbox's disabled look:

  and disabled: a table needs a name per row and at least one column.

reorder as optional; it is left out until a table needs it, because it
needs a keyboard way to move as well.

## When to use

Use a Column Chooser on a table with more columns than most people need at
once, typically six or more, where different people read different ones.

<DoDont
  do={<Story of={ColumnChooserStories.DoFewColumns} />}
  doCaption="A few optional columns beside a locked name column."
  dont={<Story of={ColumnChooserStories.DontTwoColumns} />}
  dontCaption="A chooser for two columns: one is locked, so there is nothing to choose."
/>

## When not to use

- **To switch between whole layouts** (a summary and a detailed set): use
  saved views, so one choice changes several columns at once.
- **To filter rows.** Hiding a column does not hide rows; use filters in
  the table's toolbar.
- **For a table that fits.** If every column fits on the screens it is
  used on, leave them all shown.

## Accessibility

- The button reports `aria-haspopup="dialog"` and `aria-expanded`. The
  popup is a `role="dialog"` named by the label, "Columns".
- Opening moves focus into the dialog; Escape closes it and returns focus
  to the button.
- Each column is a checkbox named by its header, in table order; Space
  toggles it, and the shown keys are reported in column order, the row
  header always among them.
- The row header column's checkbox, and the last checked one, are
  `aria-disabled`: ticked and unchangeable.
- Reset is a button named "Reset" that brings back the default columns.
