# Popover

A small panel anchored to a button, for content you interact with: a
share form, a filter, a set of options. It opens on click, stays until
you close it, and holds links, inputs and buttons, which a Tooltip must
not. Spec:
[uiguideline.com/components/popover](https://www.uiguideline.com/components/popover).
Behaviour from Base UI's [Popover](https://base-ui.com/react/components/popover).

## Anatomy

| Part | What it is |
| --- | --- |
| **Trigger** | `trigger`: one button. Popover merges its props onto it. |
| **Popup** | `--popover` surface, 1px `--border`, `--shadow-md`, `--radius-panel`, 16px padding, at most 22rem wide. |
| **Title** | Optional. Names the dialog. |
| **Description** | Optional, `--muted-foreground`. Describes the dialog. |
| **Body** | `children`. |
| **Close button** | Optional, in the corner. |
| **Arrow** | Optional. |

### Design notes

- **Same surface as the Select list.** Popover, Select and Combobox
  popups share the `--popover` colour, border and shadow, and the same
  z-index layer (50); tooltips sit above them at 60.
- **No arrow by default.** The popup opens 6px from its trigger and
  lines up with it; the arrow is there for when the popover could be
  read as belonging to something else nearby.

## Accessibility

- The popup is a `role="dialog"` named by `title` (or `aria-label`) and
  described by `description`. The trigger carries `aria-expanded` and
  `aria-haspopup`.
- Opening moves focus into the popup; Escape or a click outside closes
  it and returns focus to the trigger.
- **Non-modal by default:** Tab can leave the popup, and the page stays
  usable. `isModal` switches to Base UI's modal mode: focus is trapped,
  page scroll is locked and clicks outside are blocked.
- Base UI only traps focus when the popup contains a close button, and a
  touch screen reader needs one to get out. So a modal popover without
  `hasCloseButton` still renders one: hidden until it has keyboard focus,
  then shown in the corner, so focus is never invisible.

  <Canvas of={PopoverStories.Modal} />

- `openOnHover` adds hover to click, it does not replace it: the content
  stays reachable by keyboard and touch.
