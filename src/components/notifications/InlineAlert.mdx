# Inline Alert

<DocTabs>
<DocTab value="overview">

A one-line message in the flow of a form or a section, with no box, no
title and no close button: "Changes are saved automatically", "Couldn't
reach the server".

<Status of={InlineAlertStories} />

<Canvas of={InlineAlertStories.Variants} />

## Variants

`variant` is the colour, by meaning, and the whole line takes it.

| Variant | Use for |
| --- | --- |
| `info` | A fact about what is above it: "Changes are saved automatically." |
| `success` | A check that passed: "Domain verified." |
| `warning` | A consequence to know before going on: "This link expires in 24 hours." |
| `danger` | Something that failed: "Couldn't reach the server." |

## Color

The whole line, icon and message, takes the variant's text colour. An Alert
can keep its message in `--foreground` because its box carries the colour;
an inline alert has no box, so the text does. Every `--*-text` token is
4.5:1 on the page in both modes, so a message of any length stays readable.

## When to use

Use an Inline Alert for a short message about the thing right above it: a
group of fields, a whole form, a section. A failed submit is the common
case.

<Canvas of={InlineAlertStories.InAForm} />

  do={<Story of={InlineAlertStories.DoFieldError} />}
  doCaption="An error about one field goes on the field, as its helper text: it is read when the field is focused."
  dont={<Story of={InlineAlertStories.DontForOneField} />}

## When not to use

- **For an error on one field.** Use the field's own `validationState` and
  `helperText`, tied to it with `aria-describedby`.
- **For a message about a whole page or region**, or one that needs a
  title, an action row or a close button. Use an
  [Alert](?path=/docs/components-notifications-alert--docs).
- **For news about something that just happened.** Use a
  [Toast](?path=/docs/components-notifications-toast--docs).

## Accessibility

- A plain `<div>` by default, read in order with the page.
- `isLive` for a message that appears in response to something (a failed
  submit): `danger` and `warning` become `role="alert"` and are read at
  once, `info` and `success` become `role="status"` and wait.
- The icon is `aria-hidden`: the words carry the meaning.
- The action is whatever you pass (a Link, a Button) and keeps its own
  keyboard behaviour and focus ring.
