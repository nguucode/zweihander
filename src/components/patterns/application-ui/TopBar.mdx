# Top Bar

The bar above the page: `start`, a middle and `end` slots, and `TopBarNav`
for navigation links across it. One of the three pieces the
[App Shell](?path=/docs/templates-application-ui-app-shell--docs) template places; inside
one it also shows the shell's `brand`. It was `AppHeader` (and
`TopBarNav` was `AppNav`).

```sh
npx shadcn@latest add https://ontheshore.biz/zweihander/r/top-bar.json
```

## Top navigation

`TopBarNav` takes `items` (`{ label, href }[]`) and `currentHref`. Links
that do not fit scroll sideways, so on a phone they stay in the bar.

## Props

| Prop | Values | Default | |
| --- | --- | --- | --- |
| `start` | node | – | Breadcrumbs, or TopBarNav links. |
| `children` | node | – | The middle, e.g. a wide search field. |
| `end` | node | – | Search, notifications, the account menu. |

## Layout

- The bar is one row, `--control-md` plus two `--space-inline` tall (48px), padded `--space-3` at the sides, its start, middle and end
  `--space-inline` apart and the items inside the start and the end `--space-stack` apart, as Atlassian's top nav; controls in it are 32px (`md` buttons, `sm` fields). Its fill and edge come from the App Shell's top cell
  (solid or transparent), not from the bar.
- In the shell's top-bar layout with a sidebar, the brand takes a cell as
  wide as the sidebar (`--sidebar-width`), so the logo's left edge is where
  it is in the sidebar layout, on the nav icons' column. It is centred on
  the bar, 24px from the top; in the sidebar layout it sits in Atlassian's
  side nav header instead, centred 28px from the top.
- Breakpoints read the container, which in an app is the shell.

## Accessibility

- The bar is a `header`; inside an App Shell it is the page's banner.
- `TopBarNav` is a `nav` named "Main"; the current page has
  `aria-current="page"` and is shown by more than colour.
