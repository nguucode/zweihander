# Patterns

Whole sections of a screen, assembled from Components (atomic design's
"organisms"). Where a component is a building block, a pattern is a
finished arrangement of them: a page heading, a row of stats, a settings
form.

Patterns are meant to be **copied and edited**, like Tailwind Plus blocks.
They ship through the registry only, not the npm package: install one and
its file lands in your project, next to the components it uses, as code
you own.

```sh
npx shadcn@latest add https://ontheshore.biz/zweihander/r/page-heading.json
```

Each pattern is a small React component that takes its content as props,
so a variant is usually a matter of which props you pass. The stories show
the variants side by side, and each one is checked for accessibility like
any component.
