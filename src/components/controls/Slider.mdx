# Slider

<DocTabs>
<DocTab value="overview">

Picks a number, or a range, by dragging along a track: volume, a price
range, a brush size.

<Status of={SliderStories} />

<Canvas of={SliderStories.Default} />

## Variants

One value or two: a `defaultValue` (or `value`) that is an array of two
makes a range, with a thumb at each end.

<Canvas of={SliderStories.Range} />

| Size | Use for |
| --- | --- |
| `md` | The default: a 20px thumb on a 6px track. |
| `sm` | Dense panels and toolbars: a 16px thumb on a 4px track, 12px label. |

## States

<States
  states={[
    { label: 'Enabled' },
    { label: 'Focus', pseudo: 'focus-visible' },
    { label: 'Disabled', content: <Story of={SliderStories.Disabled} /> },
  ]}
>
  <Slider label="Volume" defaultValue={40} showValue />
</States>

- **Focus** is a 2px `--ring` outline, 2px outside the thumb.
- **Dragging** changes the cursor to a closed hand.
- **Disabled** dims the track and thumbs to 50%. The label turns
  `--muted-foreground` and the value stays as it was, so both still read
  at 4.5:1: they are not a native `<label>`, so faded text would fail
  contrast rather than be exempt as part of a disabled control.

## When to use

Use a slider when an approximate value is fine and seeing it change helps:
volume, brightness, a price range to filter by. Show the value with
`showValue` so the reader knows where they landed.

<DoDont
  do={<Story of={SliderStories.DoApproximate} />}
  doCaption="An approximate value, with the number shown as it moves."
  dont={<Story of={SliderStories.DontExactNumber} />}
  dontCaption="An exact figure on a long scale: 137 out of 500 is fiddly to hit by dragging. Use a Number Input."
/>

## When not to use

- **For an exact number** (a price, a quantity). Use a Number Input, or
  pair one with the slider.
- **For a few named options.** Use a
  [Radio](?path=/docs/components-controls-radio--docs) group, so each
  option says what it means.
- **For a score out of five.** Use a
  [Rating](?path=/docs/components-controls-rating--docs).

## Accessibility

- Each thumb is a `role="slider"` (a real range input) with
  `aria-valuenow`, `aria-valuemin`, `aria-valuemax` and a formatted
  `aria-valuetext`.
- A single thumb is named by `label`, or `aria-label`; a range needs
  `thumbLabels` so each thumb says which end it is.
- Keyboard: arrows move by `step`, Page Up / Page Down and Shift+arrows
  by `largeStep`, Home and End jump to `min` and `max`.
- The fill clears 3:1 on the track for every accent.
- Thumbs keep their size and grow a 44px hit area on coarse pointers.
