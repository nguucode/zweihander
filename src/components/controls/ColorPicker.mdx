# Color Picker

<DocTabs>
<DocTab value="overview">

Chooses a colour: type it in any CSS format, pick a swatch, find it on a
saturation and brightness area and a hue strip, or type its channels in
Hex, RGB, HSL or HSB. The panel is laid out like Figma's colour picker.

<Status of={ColorPickerStories} />

<Canvas of={ColorPickerStories.Default} />

## Variants

Two exports.

| Export | Use for |
| --- | --- |
| `ColorPicker` | A form field: the hex in a text field, with a swatch button that opens the panel in a popover. |
| `ColorPanel` | The panel on its own, always open: a sidebar, an inspector, a settings page about colour. |

<Canvas of={ColorPickerStories.Panel} />

`alpha` adds opacity; `defaultFormat` picks which channels the fields show
first.

<Canvas of={ColorPickerStories.FormatsAndOpacity} />

## Color

The area, the hue strip and the checkerboard are the colour model itself,
so they are fixed colours, not theme tokens. The thumbs are white rings
with a dark edge: one of the two is at least 3:1 against whatever colour
is under them.

in dark, as in Figma. That is below the 3:1 of WCAG 1.4.11 round a white
swatch on white, accepted because the hex in the field, not the edge,
tells the colour.

- **Focus** follows Text Input on the field. In the panel every thumb,
  swatch and field draws a 2px `--ring` outline, 2px outside.
- **Disabled** dims the field and disables the swatch button.
- **Error** is Text Input's. Typed text that is not a colour turns the
  field to error on its own, with a hint, and keeps the last good value.
- **Chosen swatch** has a 2px `--primary` ring; focused as well, the ring
  turns `--ring` and moves 1px further out.

## API

{/* Storybook's table does not scroll by itself on a phone. */}
<div style={{ overflowX: 'auto' }}>
  <ArgTypes of={ColorPickerStories} />
</div>

`ColorPanel` takes `value`, `defaultValue`, `onValueChange`, `alpha`,
`defaultFormat`, `swatches`, `disabled` and `className`.

`parseColor(text)` reads any CSS colour (`rgb(59 130 246)`,
`hsl(217 91% 60% / 50%)`, `oklch(...)`, `rebeccapurple`) to the same hex,
or `null`; the browser parses it, so outside one only hex is read.
`normalizeHex(text)` turns `#abc`, `ABC` or `#AABBCC` into `#aabbcc`,
keeps an alpha byte (`#3b82f680`, or `#abc8` as `#aabbcc88`) unless it is
`ff`, and turns anything else into `null`.

### Design notes

- **Hex in, hex out.** The value is lowercase `#rrggbb`, with an alpha
  byte only while opacity is under 100%. Typed text is read on Enter or
  blur: hex of 3, 4, 6 or 8 digits with or without `#`, or any CSS colour.
  It is shown back as hex.
- **Formats are a view, not a value.** RGB, HSL and HSB only change the
  fields; the value stays hex. Channel fields commit on Enter or blur, and
  up and down step by 1 (Shift by 10), as in a design tool.
- **The hue is remembered.** The picker keeps hue, saturation and
  brightness, so dragging to black and back leaves the hue strip where it
  was instead of jumping to red.
- **Not in this version:** Figma's library picker ("On this page"),
  gradients and an eyedropper.

## When to use

Use a colour picker when any colour is a valid answer: a brand colour, a
chart series, a label someone defines. When there is a palette to follow,
offer it as named swatches.

## When not to use

- **For a few fixed colours.** When only a set of colours is allowed (tag
  colours, a theme accent), use a
  [Radio](?path=/docs/components-controls-radio--docs) group of swatches or
  a Select: the picker lets anyone type any colour.
- **To show a colour.** Use a swatch and its hex as text.

## Accessibility

- The field is a text input named by its label. The swatch button is
  named "Choose colour, #3b82f6 selected", and the popover is a dialog
  named "Choose colour" that returns focus to the button on Escape.
- The area is one tab stop: a slider named "Saturation" whose value text
  reads both numbers ("Saturation 76%, brightness 96%"). Left and right
  change saturation, up and down brightness, Shift moves 10%, Page Up and
  Page Down change brightness by 10%, Home and End set saturation to 0 or
  100%. A second "Brightness" slider is there for a screen reader's
  browse mode.
- The hue strip is a slider named "Hue", read as "217 degrees"; the
  opacity strip, "Opacity", read as "50%".
- The format menu is the kit's Select, named "Colour format". Channel
  fields are text inputs named for what they hold ("Red", "Hue degrees",
  "Lightness percent", "Opacity percent", "Hex"), so they do not share a
  name with the sliders.
- Swatches are native radios in a radio group named "Swatches": one tab
  stop, arrows move and choose, and the chosen one is checked. None is
  checked while the colour is not one of them. They are 24px with 8px
  between them, which meets WCAG 2.5.8 without a larger invisible target.
- A colour is never the only way to know the value: the hex is always in
  the field.
