# Avatar

A picture of a person or account, with initials when there is no
picture. Neutral by default, or any accent hue as a tint or a solid fill. Spec:
[uiguideline.com/components/avatar](https://www.uiguideline.com/components/avatar).

<Canvas of={AvatarStories.Fallbacks} />

## Anatomy

| Part | What it is |
| --- | --- |
| **Container** | The circle or square, in `color` and `variant`. Clips its content. |
| **Image** | `imageSrc`, cropped to fill (`object-fit: cover`). |
| **Initials** | `initials`, shown when there is no image or it fails to load. |

## Props

| Prop | Values | Default | |
| --- | --- | --- | --- |
| `size` | `xs`, `sm`, `md`, `lg` | `sm` | 24, 32, 40, 48px. |
| `imageSrc` | string | – | |
| `imageAlt` | string | – | Who this is. See Accessibility. |
| `initials` | string | – | Not in the spec's prop list; see below. |
| `appearance` | `circle`, `square` | `circle` | |
| `color` | any accent hue | – | Unset is the neutral gray. |
| `variant` | `subtle`, `solid` | `subtle` | Solid is the hue's 600 step (400 in dark). |

Every other `<span>` attribute passes through to the container.

### Differences from the spec

- **`initials` is added.** The spec's Anatomy has an Initials part but
  its prop list has no way to set them. Pass the letters, not a name:
  how to abbreviate a name depends on the language, and the kit should
  not guess.
- **A broken image falls back** to initials or the placeholder instead
  of showing the browser's broken-image icon. A new `imageSrc` is tried
  again.
- **No placeholder icon.** With neither image nor initials the avatar
  is the empty coloured shape: a generic person icon says nothing the
  shape does not.
- **`color` and `variant` are added.** Colour tells people apart in a
  list; it carries no meaning, so pick it from the person (a hash of
  their id) rather than from a status.
- **Circle ignores the radius preset**; square follows it
  (`--radius-md`).

### Colour

<Canvas of={AvatarStories.Colors} />

`color` sets the Theme's own `data-accent` on the avatar, so it uses the
same measured palette as everything else: `subtle` is the hue's 100 tint
(950 in dark) with the nearest step that reads on it, `solid` is the
accent fill and its label. Behind a photo the colour only shows while it
loads or where the image is transparent.

## Accessibility

- `imageAlt` names the **whole avatar**, not just the image, so the
  image, the initials and the placeholder all announce the same person.
  The inner `<img>` has `alt=""`.
- Without `imageAlt` the avatar is **decorative** and hidden. That is
  right when the person's name is already printed next to it; announcing
  it twice is noise.
- Initials are uppercased with CSS, so screen readers get the letters as
  passed.
- Initials meet 4.5:1 in every colour and variant. The hue pairs are
  measured by the token build, which fails if a ramp edit breaks one;
  neutral solid is gray 600 under gray 50, 6.5:1 or more on every gray
  ramp.
