# Kbd

<DocTabs>
<DocTab value="overview">

A key cap that shows which key to press: a glyph like ⌘ or ⇧, a letter,
or a short word like Esc.

<Status of={KbdStories} />

Kbd is outside the 1.0 component list, so it starts as experimental.

<Canvas of={KbdStories.Sizes} />

## Variants

| Form | Use for |
| --- | --- |
| <Kbd>Esc</Kbd> one key | A single key: `children`. |
| <Kbd keys={['⌘', 'K']} /> combination | Keys pressed together: `keys`, one cap per key. |

<Canvas of={KbdStories.Combination} />

`size="sm"` (16px) fits inside a small control or a dense row; `md`
(20px) is the default, for running text, tooltips and menus.

<Canvas of={KbdStories.InText} />

## States

A key cap is not interactive: no hover, focus or pressed. Its states are
what it shows.

## When to use

Use Kbd wherever the page tells someone which key to press: a hint in a
tooltip, a command palette row, a line of help text, a shortcuts sheet.
These are places where people come to learn a shortcut, so the key gets a
cap. A Menu is not: see below.

<DoDont
  do={<Story of={KbdStories.DoHideInControl} />}
  doCaption="Inside a control the caps are hidden and the button says Meta+K through aria-keyshortcuts: its name stays “Search”."
  dont={<Story of={KbdStories.DontLeaveInName} />}
  dontCaption="Left in, the glyphs join the name: a screen reader hears “Search ⌘ K”, and ⌘ is read as “place of interest”."
/>

Match the platform: ⌘ and ⌥ on a Mac, Ctrl and Alt elsewhere. Kbd shows
what it is given and does not detect the platform.

## When not to use

- **For a Menu item's shortcut.** Use Menu's `shortcut` string: menus
  show shortcuts as quiet text at the end of the row, the way desktop
  menus do. The menu is for acting, and a cap on every row would pull the
  eye from the labels. A command palette is the exception: it is where
  shortcuts are discovered, so its rows use Kbd.
- **For code or a value someone types.** Use `<code>`: Kbd is a key, not
  text to copy.
- **To bind the key.** Kbd is display only; the page binds the shortcut.

## Accessibility

- Kbd is a native `<kbd>`; a combination is a `<kbd>` of `<kbd>`s, one
  per key.
- It is not focusable and has no role: it is never in the tab order.
- In running text it is read where it sits, as text: "Press Esc to close".
  A combination's keys are read one after the other with no "plus" (⌘S);
  write the combination out in the sentence when that matters.
- Inside a control, hide it with `aria-hidden` and put the shortcut on the
  control with `aria-keyshortcuts` (for example `Meta+K`), so the
  control's name stays its label.
- Contrast is checked by addon-a11y in error mode for every story.
