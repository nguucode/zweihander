Add the Grid List pattern (`grid-list`, registry only): records as cards in a grid that fits as many columns as its container allows. A card takes the same item as a Stacked List row (media, title, status, description, meta, `href`, Menu `actions` with a context menu) plus an optional `cover` picture; the card panels, footer and empty state come from List Container. Install with `npx shadcn@latest add https://ontheshore.biz/zweihander/r/grid-list.json`.
