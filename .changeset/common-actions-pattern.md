Add the Common Actions pattern (registry only): `commonActions` gives Create, Add, Edit, Save, Cancel, Close, Duplicate, Archive, Remove, Delete, Import, Export and Undo one label, placement, button style, confirmation level (none, undo toast, confirm dialog, type to confirm) and shortcut each, and `CommonActionsTable` renders it as a reference table. Install with `npx shadcn@latest add https://ontheshore.biz/zweihander/r/common-actions.json`.
