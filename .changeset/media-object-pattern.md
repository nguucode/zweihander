Add the Media Object pattern (`media-object`, registry only): an Avatar, Icon or image beside a title and description. `align` puts the media at the top, middle or bottom of the text or stretches it, `mediaPosition` puts it on either side, `headingLevel` makes the title a heading, and `children` takes actions or nested replies. The text wraps under the media in a narrow container. Install with `npx shadcn@latest add https://ontheshore.biz/zweihander/r/media-object.json`.
