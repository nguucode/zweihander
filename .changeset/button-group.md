Add Button Group (`zweihander/button-group`): `ButtonGroup` joins Buttons into one bar, and `ToggleGroup` (Base UI Toggle Group) joins ToggleButtons that share one selection, one at a time (a segmented control) or several with `multiple`. ToggleButton now picks up `disabled` from a disabled ToggleGroup; its own API is unchanged.
